Introduction

Building the Website Behind the Service

Rogelio Tradio Jr., also known as Kidoy, is the IT Developer / Website Developer for SureCargo Transport. He develops and maintains the website that customers use to learn about our routes, services, and team.

The website is built with a focus on simplicity, readability, and responsiveness — so it works well on phones, tablets, and desktop computers.

Website Development Responsibilities

The website is built with clean, semantic HTML, modern CSS, and lightweight vanilla JavaScript. There are no external frameworks or build processes — the site is a simple static website that loads quickly and is easy to maintain.

Development work includes building new pages, updating content, and making sure that links, navigation, and interactive features work correctly.

Website Maintenance & Usability

Keeping the website up to date is part of the IT developer's role. Content like team profiles, route pages, and contact details can be edited directly in the HTML files without needing a database or server-side technology.

Usability improvements — from clearer navigation to better mobile layouts — help customers find the information they need quickly.

Technologies Used

This website is built using HTML5, CSS3, and vanilla JavaScript only. No build tools, frameworks, or databases are required — which keeps the site lightweight and easy to host on GitHub Pages.
