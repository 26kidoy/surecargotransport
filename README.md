# SureCargo Transport — Website

A complete, mobile-responsive, static website for **SureCargo Transport**, a cargo transportation and delivery business serving:

- **Route 1:** Bantayan Island → Bacolod (egg delivery, boxes, dried seafoods, other accepted cargo)
- **Route 2:** Bantayan Island → Cebu (general cargo, commercial goods, boxes and parcels, other accepted cargo)

This website is built with **HTML5, CSS3, and vanilla JavaScript only** — no frameworks, no build process, no database. It is designed to be hosted on **GitHub Pages** or any static hosting service.
